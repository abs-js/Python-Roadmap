# Python Roadmap 🐍

Um roadmap completo para você que deseja estudar Python puro.

---

## 🚀 Como usar?

### 🛠️ Preparação do Ambiente

Antes de começar, você precisa baixar o conteúdo para o seu computador. Siga os passos abaixo para garantir um bom fluxo de trabalho:

1. **Escolha uma pasta dedicada:** Crie ou escolha uma pasta de fácil acesso no seu computador (por exemplo, dentro de `Documentos` ou `Projetos`).
2. **Clone o repositório:** Abra o terminal dentro dessa pasta e rode o comando:
   ```bash
   git clone https://github.com/SemFrescura/Python-Roadmap.git
   ```
3. **Entre na pasta:** Agora basta executar um `cd ./Python-Roadmap` e iniciar seus estudos

💡 Dica (Opcional):

Se você quiser salvar as suas respostas e o seu progresso no seu próprio GitHub como um portfólio de estudos, você pode apagar o histórico de conexão com este repositório original rodando:
`rm -rf .git`
Depois disso você pode dar um `git init` se desejar para iniciar seu novo progresso

**ATENÇÃO:** Se você fizer isso perderá toda conexão com o repositório original perdendo acesso á atualizações usando `git pull` e terá de executar novamente o `git clone`.

### 📁 Capítulos
É muito simples: cada conteúdo está na pasta `./trilha`, separado por tópicos.  
Cada pasta representa um capítulo e contém um arquivo `capitulo.md` com:

- 📖 Uma introdução sobre o assunto
- 💡 Uma analogia explicativa
- 🏋️ Um desafio prático
- 🔑 O gabarito (olhe só depois de praticar!)
- ❓ Perguntinhas para fixação

Dentro dessas pastas, você tem total liberdade para criar seus arquivos e codificar. Eu recomendo fortemente que você crie o seu arquivo `main.py` tradicional para resolver o desafio e, depois, crie um `main_v2.py` — que será uma versão refatorada e melhorada por você mesmo!

### 🗺️ INDEX
O arquivo `./INDEX.md` é o seu guia. Ele contém todos os capítulos em ordem cronológica, como um índice claro.  
A verdadeira função dele é servir como um **marca-páginas**: a cada capítulo concluído, marque um `X` entre os colchetes `[ ]`. Assim, você acompanha seu progresso e sabe exatamente onde parou.
